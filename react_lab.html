This course is designed for developers who previously worked in vanilla JavaScript and are returning to web development — specifically to learn React.js from a practical, project-first perspective. Each week builds directly on the last, progressing from JavaScript refresher and toolchain setup through component architecture, state management, API integration, and a final deployable project. Daily sessions run 1–3 hours depending on your schedule. Exercises are short and hands-on; projects are cumulative and portfolio-worthy.

Weekly Schedule
Week 01
May 27 – Jun 2, 2026
JS Refresh + React Foundations
Shake off the rust. Get React running. Understand why it exists.
Topics Covered
  • ES6+ refresher: const/let, arrow functions, destructuring, spread/rest
  • Template literals, array methods (map, filter, reduce)
  • Modules: import / export
  • What is React? Virtual DOM, component model
  • Create-React-App vs Vite setup
  • JSX syntax — HTML in JS
  • Functional components, returning JSX
  • Props: passing data parent → child
Exercises & Project
Exercise
JS30-Mini
Write 5 small scripts using only ES6+ features — destructuring objects, chaining array methods, writing arrow functions. No frameworks.

Week Project
Static Profile Card
Build a React component that renders a personal profile card using hardcoded props. Practice JSX, component structure, and passing data via props.
Week 02
Jun 3 – Jun 9, 2026
State, Events & Lists
Make your UI respond to the user.
Topics Covered
  • useState hook — reading and updating state
  • Event handlers: onClick, onChange, onSubmit
  • Controlled vs. uncontrolled inputs
  • Conditional rendering (ternary, &&&)
  • Rendering lists with .map() + key prop
  • Lifting state up to parent components
  • Component composition patterns
Exercises & Project
Exercise
Counter + Toggle Drills
Build: (1) a counter with increment/decrement/reset buttons, (2) a show/hide toggle, (3) a live character counter for a textarea input.

Week Project
Task List App
Build a to-do list where users can add, complete, and delete tasks. Renders a list from state, uses controlled inputs, and lifts state through multiple components.
Week 03
Jun 10 – Jun 16, 2026
useEffect & Data Fetching
Connect your components to the outside world.
Topics Covered
  • useEffect hook — side effects explained
  • Dependency array: [], [value], no array
  • Fetching data with fetch() and async/await
  • Loading and error states
  • Cleanup functions in useEffect
  • Introduction to custom hooks
  • Free public APIs for practice (JSONPlaceholder, OpenWeather, etc.)
Exercises & Project
Exercise
API Fetch Drills
Fetch and display data from JSONPlaceholder: (1) list of users, (2) posts by user ID, (3) add a loading spinner and an error message for a failed request.

Week Project
Weather Widget
Build a weather app using the OpenWeatherMap API. User types a city name, app fetches and displays current conditions. Handles loading, error, and empty states properly.
Week 04
Jun 17 – Jun 23, 2026
React Router & Multi-Page Apps
Build apps with real navigation.
Topics Covered
  • Single-Page App (SPA) concept
  • React Router v6 — BrowserRouter, Routes, Route
  • Link and NavLink components
  • useParams for dynamic routes (e.g. /post/:id)
  • useNavigate for programmatic navigation
  • Nested routes and layout components
  • 404 / catch-all routes
Exercises & Project
Exercise
Route Drills
Build a 3-page app (Home, About, Contact) with working navigation. Add a dynamic /user/:id route that reads the param and displays it on screen.

Week Project
Blog / Portfolio Viewer
Multi-page React app with a home feed (list of posts from an API), a post detail page (/post/:id), and an About page. Navigation via React Router. Good candidate for your own portfolio.
Week 05
Jun 24 – Jun 30, 2026
Global State & Context API
Stop prop-drilling. Share state across the whole app.
Topics Covered
  • The prop-drilling problem
  • React Context API — createContext, Provider, useContext
  • useReducer for complex state logic
  • Combining useReducer + Context (Redux-lite pattern)
  • Introduction to Zustand (lightweight state library)
  • When to use local vs global state
  • Performance: avoiding unnecessary re-renders
Exercises & Project
Exercise
Theme Toggle + Cart Drill
Build: (1) a dark/light theme toggle using Context across 3 nested components, (2) a simple shopping cart counter accessible from both a product page and a nav bar.

Week Project
Shopping Cart App
Product listing page + cart page with global state via Context + useReducer. Add/remove items, update quantities, show total. This is a classic React portfolio piece.
Week 06
Jul 1 – Jul 7, 2026
Final Project & Deployment
Ship something real.
Topics Covered
  • Project planning: wireframe → components → data
  • Form handling best practices
  • CSS in React: modules, Tailwind basics, or styled-components
  • Performance: useMemo, useCallback (intro)
  • Building for production: npm run build
  • Deployment: Netlify or Vercel (drag-and-drop or GitHub connect)
  • README writing + GitHub portfolio presentation
Final Project
Capstone
Choose Your Own React SPA
Build and deploy a complete React app of your choosing. Must include: multiple routes, data fetching from a real API, global state (Context or Zustand), loading/error handling, and a live deployment URL.

Suggested ideas: Movie search app (TMDB API), GitHub profile viewer, crypto price tracker, recipe finder, or a personal portfolio built in React.
Daily Study Expectations
  • Watch or read the day's assigned resource (30–60 min)
  • Complete at least one small coded exercise
  • Commit code to GitHub — even broken work
  • Keep a short dev log (what you learned, what confused you)
  • Build the week's project incrementally, not all at once
  • If stuck > 20 min, search docs first, then ask for help
